# Customer Churn Prediction (Machine Learning Project)

## Overview

This project predicts whether a customer is likely to churn using a Logistic Regression model.
It is designed as a simple, interactive web application using Streamlit.

---

## Objective

To demonstrate how machine learning models can be used to:

* Analyze customer data
* Predict churn probability
* Provide an interactive UI for user input

---

## Model Details

* Algorithm: Logistic Regression
* Problem Type: Binary Classification
* Output: Probability of churn

---

## Tech Stack

* Python
* Scikit-learn
* Streamlit
* Pandas / NumPy

---


## Run Locally

### 1. Install dependencies

```
pip install -r requirements.txt
```

### 2. Run app

```
streamlit run streamlit_app.py
```
